# Посещаемость 6 «Г»

Демонстрация — только вымышленные данные. Родители открывают форму без кодов; учитель входит по паролю из переменной TEACHER_PASSWORD (в демо допускается от 6 символов). Реальные данные не размещайте в демо. Node.js 22.13+, SQLite. DEMO=1 npm start; DB_PATH=/data/attendance.sqlite для постоянного тома. Для рабочего режима на подходящем хостинге отключите DEMO и задайте TEACHER_PASSWORD (12+), CLASS_CODE (10+); сохраняется защита списка и уведомлений личными кодами. Дата Asia/Almaty, день окончания включительно; по понедельникам удаляются завершившиеся записи, активные сохраняются. npm test — проверка логики дат.

Отчёт: только строки «Фамилия Имя - причина (пояснение)», без шапки и итогов. Пояснения можно отключить. Для локального рабочего развёртывания список имён импортируется через скрипт `node import-roster.mjs /path/roster.txt` с тем же DB_PATH; файл списка хранить вне репозитория и не загружать на демонстрационный сервер. Скрипт дополняет список, не удаляет существующих учеников; печатает новые личные коды в закрытом терминале.
