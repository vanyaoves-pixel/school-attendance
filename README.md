# Посещаемость 6 «Г»

Демонстрационная версия: только вымышленные данные. Не вводите реальные имена, диагнозы и иные персональные данные на зарубежном хостинге.

Node.js 22.13+, SQLite, HTML/CSS/JS. Для демонстрации: `DEMO=1 npm start`. Для постоянного хранения подключите volume `/data`, `DB_PATH=/data/attendance.sqlite`. Для рабочей установки на подходящем хостинге задайте `TEACHER_PASSWORD` (от 12 символов), `CLASS_CODE` (от 10 символов), отключите `DEMO` и используйте HTTPS. В режиме DEMO: код класса `demo-class-2026`, пароль учителя `demo-teacher-2026`, код вымышленных учеников `12345678`. Даты по Asia/Almaty; последний день включительно; еженедельная очистка завершившихся периодов, активные сохраняются.
